  NORRE GAMES HOST SUITE (PS4 FW 9.00 GoldHEN)
=================================================

Bonjour NORRE GAMES !

Voici ton hôte web PS4 personnalisé, utilisant tes deux logos.

Contenu du pack :
- assets/             : Dossier contenant tes images
  - (Tu dois y copier tes fichiers)
- index.html          : L'interface utilisateur moderne (Thème Dark Glassmorphism)
- style.css           : Les styles adaptés à ta charte graphique
- exploit.js          : Le gestionnaire de cache hors-ligne
- cache.appcache      : Le fichier manifest pour l'accès hors-ligne
- goldhen.bin         : Emplacement pour ton chargeur GoldHEN (à copier ici)

INSTRUCTIONS D'INSTALLATION :

1. Hébergement :
   - Dépose le dossier principal sur GitHub Pages, un serveur local (Apache/Python) ou sur ton ESP32/Smartphone.

2. Gestion des Logos (CRUCIAL) :
   - J'ai créé l'interface pour utiliser tes images, mais je ne peux pas les inclure directement dans le ZIP.
   - **Tu dois toi-même copier tes images d'origine** dans le dossier `assets/` de ton hôte.
   - Renomme `image_1.png` en `logo_simple.png` (pour la marque d'en-tête).
   - Renomme `image_2.png` en `logo_3d.png` (pour l'icône GoldHEN).

3. Premier chargement sur PS4 :
   - Assure-toi que la PS4 est connectée à Internet.
   - Ouvris le navigateur PS4 et entre l'adresse de ton hôte.
   - Patientez pendant le téléchargement (jusqu'à "Cache Prêt Hors-Ligne" et 100% de progression).

4. Utilisation Hors-Ligne :
   - Désactivez le Wi-Fi/Ethernet dans les paramètres de la PS4.
   - Ouvrez le navigateur ou le Guide de l'utilisateur : la page se chargera instantanément depuis le cache local.
